# Career Forms Platform

Конструктор форм отклика для стажировок. Решает проблему долгого вывода новых форм на продакшен.

## Запуск проекта
Решение полностью автономно и не требует внешних баз данных или компиляции нативных модулей.

1. Установите зависимости: `npm install`
2. Запустите сервер: `npm start`
3. Откройте админку: `http://localhost:3000/admin`

*Порт настраивается через переменную окружения `PORT` (по умолчанию 3000).*

## Стек
- **Backend:** Node.js, Express
- **Хранилище:** Локальный JSON-файл (`data/app.json`). Выбрано вместо SQLite для 100% гарантии успешного выполнения `npm install` в любой среде без необходимости компиляции нативных модулей (`node-gyp`), что строго соответствует требованию автономности и простоты запуска.
- **Frontend:** EJS, Vanilla JS, CSS (без тяжелых фреймворков для простоты поддержки).

## Архитектура и планы на продакшен
Текущее решение использует JSON-файл для полной автономности в рамках тестового задания. 
Для боевой версии планируется:
1. Замена JSON-хранилища на PostgreSQL для поддержки параллельных записей и транзакций.
2. Добавление middleware авторизации (JWT/Session) для `/admin`.
3. Подключение S3-совместимого хранилища для загрузки файлов (резюме), когда это будет разрешено инфраструктурой.
4. Расширение конструктора для создания не только форм, но и SEO-страниц и страниц работодателей (архитектура маршрутов уже готова к этому).
