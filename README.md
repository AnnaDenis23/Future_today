# Career Forms Platform

Тестовое задание: конструктор форм отклика для стажировок.

## Запуск проекта
1. Установите зависимости: `npm install`
2. Запустите сервер: `npm start`
3. Откройте админку: `http://localhost:3000/admin` (в Codespaces используйте вкладку Ports -> порт 3000).

## Стек
- **Backend:** Node.js, Express
- **База данных:** SQLite (better-sqlite3) — используется для полной автономности (без внешних серверов).
- **Frontend:** EJS (шаблонизатор), чистый CSS и Vanilla JS (без тяжелых фреймворков).

## Архитектура и продакшен
Для боевой версии я бы заменила SQLite на PostgreSQL (для надежности и параллельных записей), а для хранения загруженных резюме использовала бы S3-хранилище. Авторизацию для админки добавила бы через JWT или сессии.
