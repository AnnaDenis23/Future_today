# История работы с AI

В данной папке представлена полная, неизменённая история взаимодействия с искусственным интеллектом в процессе выполнения тестового задания.

## Инструменты и модели
- **Инструмент:** Qwen (веб-интерфейс / API)
- **Модель:** Qwen 3.7
- **Цель использования:** 
  1. Анализ технического задания и выявление критических рисков (например, проблема с компиляцией нативных модулей вроде `better-sqlite3` при запуске `npm install`).
  2. Рефакторинг архитектуры: переход на автономное JSON-хранилище для гарантии запуска в любой среде.
  3. Написание бэкенд-валидации данных формы.
  4. Формулировка ответов в `ANSWERS.md` с акцентом на бизнес-контекст задачи (проблема "понедельник-четверг", риски зависимости от AI).

## Содержимое папки
- `session-1.txt` — Полный, неизмененный лог диалога (copy-paste), включающий запросы, анализ предыдущих ошибок и финальную генерацию кода. Диалог предоставлен целиком, без сокращений и пересказа, в соответствии с требованиями ТЗ.

## Примечание
История предоставлена в прозрачном виде, чтобы продемонстрировать реальный процесс разработки, степень участия AI и осознанные инженерные решения, принятые на основе его рекомендаций.
